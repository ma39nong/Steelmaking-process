# 全炉强候选逐点复核补充

在预声明自动规则完成全炉审查后，5个强候选全部逐点核对真实邻域。766.413nm候选所在谱线在邻帧持续、且当帧邻通道共同增强，自动“中位数显著性持续比例”不足以排除宽谱线。故采用只减不增的原始点复核账本，将该点从高可信修复集降为一般疑似并保留。其余4点为统计支持的孤立尖峰，仍不声称已确认仪器故障。

该账本在开发选型/确认之前建立；不改变任何人工注入位置、参考质量、检测得分或阈值。不将人工试验中的假阳性事后人工删去。人工端到端表报告完整自动规则，最终原始点处理另要求可复核的保留否决步骤，所有否决单独输出。以后新数据必须重新逐点复核，不把这份特定炉次账本泛化为自动谱线鉴别器。初始5点自动结果保留在audit_before_line_review中。
