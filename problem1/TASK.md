# 一、研究任务与问题边界

## 1.1 第一问原始要求

附件1至附件10包含十炉次转炉炼钢过程的离散火焰光谱数据。

光谱数据按照时间和波长排列，存在异常点，需要：

2. 对离散光谱数据进行连续重构。
3. 建立时间—波长—光强的连续数学表达。
4. 绘制全部十炉次的连续三维光谱曲面。

## 1.2 数学问题定义

对第 \(h\) 个炉次，定义：

\[
Y_h=\{I_h(t_i,\lambda_{h,j})\}
\]

其中：

- \(h=1,\ldots,10\)：炉次编号。
- \(t_i\)：实际采样时间。
- \(\lambda_{h,j}\)：该炉次第 \(j\) 个实际波长。
- \(I_h(t_i,\lambda_{h,j})\)：测量得到的光谱强度。

目标是建立：

\[
\boxed{\widehat I_h(t,\lambda)}
\]

使其能够在整个观测时间—波长区域内连续计算光谱强度。

注意：

第一问只研究火焰光谱矩阵。

累计氧耗、CO₂和CO属于后续问题，不允许将其作为第一问光谱重构模型的输入变量。可以保留用于数据审计，但不得混入第一问的拟合过程。

# 七、第五阶段：异常值检测模型

至少研究三个层面的异常。

## 7.1 局部异常检测

采用局部中位数和MAD（Median Absolute Deviation）构建鲁棒异常检测。

考虑时间—波长二维邻域。

对每个观测点计算：

\[
r_{ij}=Y_{ij}-\operatorname{Median}(\mathcal N_{ij})
\]

根据局部MAD计算鲁棒标准化残差。

不能仅使用单一固定阈值，应测试不同邻域大小和阈值的影响。

## 7.2 整体光谱异常检测

借鉴Agahian和Funt的鲁棒Mahalanobis距离方法。

由于2047维波长通道可能高于有效样本数量，不能直接使用普通高维协方差矩阵。

先使用PCA或低秩表示提取光谱低维特征，再考虑：

- Robust Mahalanobis Distance。
- Fast-MCD。
- 异常光谱聚类。

对于异常光谱，不允许直接全部删除。

需要判断其究竟是仪器异常，还是可能反映真实的冶炼状态变化。

## 7.3 时间和波长方向异常

分别检查：

- 某个时间点整体异常。
- 某个波长通道持续异常。
- 连续时间区间异常。
- 局部饱和区域。

最终建立统一异常掩码：

\[
M_{ij}=
\begin{cases}
1,&\text{有效观测}\\
0,&\text{无效或需要重构}
\end{cases}
\]

同时保存异常类型，不能只保存一个0/1标记。

输出：

- 每个炉次异常值数量。
- 异常比例。
- 不同类型异常比例。
- 异常位置。
- 异常分布图。

# 八、第六阶段：连续重构模型建立

这是第一问的核心。

必须实现以下三个模型进行对照。

## 8.1 模型A：传统滤波与样条插值基线

建立：

Hampel异常检测 → Savitzky-Golay平滑 → 三次样条插值。

需要注意：

标准Savitzky-Golay滤波要求等间隔采样。我们的波长轴可能非均匀。

因此：

- 可以直接在均匀时间轴上使用SG。
- 波长方向如果使用标准SG，必须先进行明确的均匀网格转换。
- 也可以使用基于实际波长坐标的局部多项式回归。
- 不允许直接把非均匀波长当成均匀波长使用标准SG。

该模型作为传统方法基线。

## 8.2 模型B：低秩—稀疏分解模型

借鉴高光谱图像去噪研究。

基本思想：

\[
Y=L+S+E
\]

其中：

- \(L\)：主要光谱结构。
- \(S\)：稀疏异常分量。
- \(E\)：随机噪声。

考虑：

- Robust PCA。
- 低秩约束。
- 时间方向TV。
- 波长方向TV。

建立适用于时间—波长矩阵的模型。

注意：

原论文中的空间维度在我们这里对应时间维度，不能直接照搬原始空间假设。

如果存在饱和或缺失数据，采用带掩码的拟合方式。

该模型作为第二种对照方法。

## 8.3 模型C：鲁棒二维张量积B样条模型

这是我们的主模型候选。

借鉴Eilers等人的多维张量积B样条平滑方法，以及Castaño和Kunoth的鲁棒样条拟合思想。

建立：

\[
F_h(t,\lambda)=
\sum_{p=1}^{K_t}
\sum_{q=1}^{K_\lambda}
c_{pq}B_p(t)B_q(\lambda)
\]

其中：

- \(B_p(t)\)：时间方向B样条基函数。
- \(B_q(\lambda)\)：波长方向B样条基函数。
- \(c_{pq}\)：待估计系数。

使用Huber损失构建鲁棒目标函数：

\[
\begin{aligned}
\min_C\quad
&\sum_{(i,j)\in\Omega}
w_{ij}\rho_\delta
\left[
Y_{ij}-F_h(t_i,\lambda_j)
\right]\\
&+\alpha_t\|D_t^{(2)}C\|_F^2\\
&+\alpha_\lambda\|C(D_\lambda^{(2)})^T\|_F^2\\
&+\alpha_{t\lambda}
\|D_t^{(1)}C(D_\lambda^{(1)})^T\|_F^2
\end{aligned}
\]

其中：

- \(\Omega\)：有效观测集合。
- \(w_{ij}\)：鲁棒权重。
- \(\rho_\delta\)：Huber损失函数。
- \(D_t,D_\lambda\)：两个方向的差分惩罚算子。
- \(\alpha_t,\alpha_\lambda\)：各向异性平滑参数。

使用迭代重加权最小二乘（IRLS）求解，或者使用等价的高效鲁棒优化方法。

### 计算实现要求

每个炉次约有数百万个光谱观测值。

禁止建立巨大的稠密设计矩阵。

必须利用：

- 张量积结构。
- B样条局部支撑。
- 稀疏矩阵。
- 分块计算。
- 迭代线性求解器。

控制内存占用，保证十炉次都能完成计算。

## 8.4 BEADS独立实验

参考Zhao等人的炼钢火焰光谱研究。

对代表性光谱曲线测试BEADS基线估计。

重点验证：

1. 是否存在明显基线漂移。
2. 是否能保留真实光谱峰。
3. 是否适合当前光谱的峰值结构。
4. 是否会消除有意义的宽峰。

BEADS只作为独立预处理实验，不预先认定它一定适用于全部数据。
