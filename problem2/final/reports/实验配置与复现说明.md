# 实验配置与复现说明

统一配置位于 `problem2/configs/q2_config.json`。默认时间步为 0.5 s，Hampel 窗口为 9，PCHIP 用于连续重构，Savitzky–Golay 导数窗口为 31，可靠时滞窗口为 121，搜索范围为 0–60 s，可靠相关阈值为 0.35。

从仓库根目录运行：

```powershell
uv run --with 'numpy<2' --with pandas --with pyxlsb --with scipy `
  python -m problem2.src.run_all --data-dir G:\亚太杯\Data

uv run --with 'numpy<2' --with scipy --with pytest pytest -q problem2/tests
```

运行结果写入 `problem2/final/results/` 和 `problem2/final/data/`。原始 XLSB 只读，运行过程不会覆盖原始文件。每炉输出包含原始变量、清洗变量、氧枪流量、累计排放量、时滞观测、模型时滞、置信度、时间映射和有效掩膜。
