# 第二问正式数据字典与接口说明

## 1. 文件位置

运行 `python -m problem2.src.q2_pipeline_v2` 后，每炉生成：

```text
problem2/final/data/{heat_id}_q2_processed.npz
```

所有数组沿同一炉次的 `time` 轴保存；窗口级时滞诊断数组沿 `delay_*_center_index` 轴保存。无可靠依据的位置使用 NaN，并由布尔掩膜明确标记。

## 2. 基础字段

|字段|形状|单位|说明|
|---|---:|---|---|
|`heat_id`|标量|—|炉次编号|
|`sequence`|`n`|—|原始 Sequence|
|`time`|`n`|s|`0.5*(sequence-sequence[0])`|
|`oxygen_cumulative_raw`|`n`|m³|原始累计耗氧量|
|`oxygen_cumulative_clean`|`n`|m³|异常点经 PCHIP 重构后的累计耗氧量|
|`oxygen_flow`|`n`|m³/s|Savitzky–Golay 近似导数，非负|
|`oxygen_from_flow`|`n`|m³|由流量梯形积分得到的累计量|
|`co_raw`, `co2_raw`|`n`|m³/s|原始 CO/CO₂ 瞬时体积流量|
|`co_clean`, `co2_clean`|`n`|m³/s|清洗重构信号|
|`total_co_emission`, `total_co2_emission`|`n`|m³|从清洗瞬时流量积分的累计排放|
|`outlier_oxygen`, `outlier_co`, `outlier_co2`|`n`|—|异常位置掩膜|

## 3. 时滞字段

对 `co` 和 `co2` 分别保存以下窗口级字段：

- `delay_{gas}_center_index`、`delay_{gas}_window_time`：窗口中心索引和时间；
- `delay_{gas}_observed`：可靠窗口中心的观测时滞，其余为 NaN；
- `delay_{gas}_valid_mask`、`delay_{gas}_observed_mask`：窗口级和时间轴级有效掩膜；
- `delay_{gas}_confidence`：相关强度、峰分离和动态激励组合置信度；
- `delay_{gas}_max_corr`、`source_std`、`target_std`、`peak_separation`、`peak_prominence`、`peak_width_samples`、`boundary_hit`：可靠性诊断；
- `delay_{gas}_support_left_index`、`delay_{gas}_support_right_index`：候选窗口实际支持范围；
- `delay_{gas}_model`：固定或约束模型在源时间轴上的推断时滞；
- `time_mapping_{gas}`、`time_mapping_{gas}_model`：`time + delay` 的观测/模型映射；
- `alignment_valid_mask_{gas}`：定义域内且映射严格递增的观测点；
- `{gas}_aligned`：仅在有效观测映射处填入清洗烟气信号，其他位置为 NaN。

## 4. 元数据与读取示例

`metadata` 是 JSON 字符串，包含参数、模型选择、异常计数、窗口总数、可靠窗口数、覆盖率、边界不可用点数和窗口间空档数。读取示例：

```python
import json
import numpy as np

def load_q2_data(heat_id, root="problem2/final/data"):
    path = f"{root}/{heat_id}_q2_processed.npz"
    data = np.load(path, allow_pickle=False)
    metadata = json.loads(str(data["metadata"]))
    return data, metadata
```

后续模型必须使用 `delay_*_observed_mask`、`alignment_valid_mask_*` 和 `delay_*_confidence`；不能将 NaN 填零，也不能把 `delay_*_model` 当作独立测量标签。第一问光谱文件通过同一 `heat_id` 只读连接，并逐炉核对 `time` 数组后使用。

## 5. 当前验收与物理解释

十炉57字段共570项历史字段比较通过，第一问十炉本地时间轴已逐点精确核对。详见 [验收报告](第二问最终验收报告.md)。观测时滞的可靠标记仅指V2算法接受；峰宽及显著性为诊断量，不参与正式筛选。置信分数不是概率，模型时滞不是独立实测标签。部分峰宽诊断可为Infinity，无法辨识的观测和模型字段可为NaN，应按掩膜及字段定义处理。
