# 表格目录

本目录预留论文表格导出位置。可直接引用的机器可读结果保存在 `../results/`：

- `process_validation.csv`：十炉原始字段与时间轴核验；
- `q2_summary.json`：逐炉处理和可靠窗口统计；
- `relationship_summary.json`：四类耗氧量—烟气关系；
- `cross_validation.json`：留一炉次验证与阈值敏感性；
- `reconstruction_evaluation.json`：重构和全字段质量检查；
- `calculus_comparison.json`：微积分一致性对照。

表格由这些结果生成，不在仓库中复制未经追溯的手工数值。
