# AI tool-use rules source note

Source: APMCM committee notice “APMCM竞赛通知丨人工智能工具使用规定”, published 2026-11-04, https://m.saikr.com/contest/notice_detail/50212 (accessed 2026-11-28 Asia/Shanghai).

Extracted requirements
- AI tools may be used as assistance, but the core model construction, algorithm design/solution, and result analysis must be independently completed by the team.
- The team is responsible for checking correctness, reliability, and academic compliance.
- AI use requires a detailed disclosure. The notice asks for tool/version, purpose and application stage, key interaction records, and adopted content plus human modifications in a PDF named “AI工具使用详情”.
- AI-generated content must be marked in the relevant body locations and the tool must be listed in references with tool name, version/model, provider, and date.
- If no AI tools are used, the paper must declare that after references.
- Unverified source, plagiarism, or noncompliance can lead to disqualification.

Application to this project
This development uses Codex as an engineering assistant. Human review and execution of data checks, model decisions, experiments, and final conclusions remain required. The final contest package should include the required disclosure if AI-assisted content remains in the submitted work.
